密岛 KeyIsland · 使用指南

本地加密的密码保险库 —— 无云端、无服务器、无后门。本指南面向普通用户，帮你完成安装、建库、存取代号、备份与恢复。

本地加密 · 无云端连接 · 数据只属于你

1. 欢迎使用密岛

密岛是一款把你的账号密码只保存在你自己电脑上的密码管理器。它和大多数"账号密码同步到厂商服务器"的工具不同：

  • 没有云端账户。你不需要注册、不需要邮箱、不需要联网。
  • 没有后门。所有数据用你的主密码在本地加密，开发者也无法打开。
  • 没有网络请求。程序运行时不与任何服务器通信（详见第 11、12 节）。
一句话安全模型：主密码 + 恢复码，是打开保险库仅有的两把钥匙。两把都丢，谁也救不了你的数据——包括密岛自己。

2. 安装与首次启动

安装

  1. 双击安装包（文件名类似 KeyIsland_x.x.x_x64-setup.exe）。
  2. 安装为当前用户级（不需要管理员权限），默认装在你的用户目录下。
  3. 安装完成后，从开始菜单或桌面快捷方式启动密岛。
如果你的电脑装有安全软件，首次启动可能被拦截。请把密岛加入白名单，否则可能表现为"图标一闪而过"（见第 13 节）。

首次启动

第一次打开会直接进入设置向导，引导你创建保险库。跟着向导走完三步即可（见下一节）。

关于"网页版"：密岛主要形态是这里安装的桌面程序。若你是通过浏览器打开的某个预览页面，那里的数据只留在内存、重启即清空，仅作功能演示；只有安装桌面版，密码才会真正落盘保存。

3. 创建你的保险库

设置向导分三步，全程在本地完成，请认真看完每一步的提示。

第 1 步 · 设置主密码

  • 要求：至少 8 位，且包含以下四类字符中的至少两类——小写字母、大写字母、数字、符号。
  • 输入框下方有实时强度条，会随你输入变化（弱 / 中 / 强）。
主密码是你打开保险库的唯一钥匙之一。它无法找回、无法重置（除非你持有恢复码）。请使用一个你记得住、别人猜不到的密码。

第 2 步 · 密码提示（可选）

可以写一句只有你自己懂的提示，万一某天想不起主密码，解锁时能看到它。提示不能包含密码本身，留空也可以。

第 3 步 · 保存恢复码（最关键的一步）

密岛会生成一串 32 位恢复码（形如 XXXX-XXXX-XXXX-XXXX-XXXX-XXXX-XXXX-XXXX，8 组 4 位）。这一屏给你三件事：

  • 复制恢复码——点到剪贴板。
  • 下载 .kirk 文件——把恢复密钥存成一个文件。
  • 勾选「我已离线保存」——只有勾选后，才能点「进入密岛」。
请务必把恢复码写在纸上、或存进 U 盘等离线位置，不要只留在电脑里。
一旦「恢复码丢失」且「主密码也忘了」，你的数据将永久不可恢复——密岛没有服务器，也没有任何后门能帮你打开。

4. 主面板与日常使用

进入保险库后，你会看到主面板。它分为三块：

  • 左侧导航：全部 / 收藏 / 分类 / 标签 / 隐藏卡片。
  • 顶部工具条：搜索、网格⇄列表切换、排序、选择（批量）、预览灵动岛、锁定、新建卡片。
  • 卡片网格：每张卡片是一个账号密码条目。

搜索

按键盘 / 键即可聚焦搜索框，输入标题、账号、平台或网址即可筛选。

卡片上能做什么

操作怎么用说明
收藏点卡片上的☆标星后可在左侧「收藏」里快速找到。
复制账号 / 密码点卡片上的复制图标复制后默认 30 秒自动清空剪贴板（可在设置关闭或调整）。
预览密码按住眼睛图标按住才显示明文，松开、移开或切走立刻隐藏——避免在屏幕上长时间暴露。
打开链接点外链图标卡片配了网址就直接打开；同时配了本地应用会弹出二选一菜单；仅配本地应用的，桌面版会启动该程序。
编辑 / 删除点铅笔 / 垃圾桶图标编辑会展示明文密码；删除需确认。

每张卡片右下角有三个小圆点表示密码强度（红=弱，黄=中，绿=强），无需解密即可显示，方便你一眼发现弱密码。

批量操作

点工具条的「选择」进入选择模式，勾选多张卡片后可批量删除。出于安全，批量删除需要重新输入一次主密码。

状态条

主面板底部常驻两行：左侧是「本地加密 · 无云端连接」的安全声明，右侧是「会话剩余 X」——距离自动锁定还剩多少时间。

5. 新建 / 编辑一张密码卡片

点工具条「新建卡片」（或卡片上的铅笔）打开编辑器。可填写的字段如下：

字段是否必填说明
标题必填给这条记录起个名字，如"GitHub"。
平台可选如 GitHub、网易云。会显示在卡片副标题。
账号必填用户名 / 手机号 / 邮箱。
密码新建必填编辑时留空表示"不修改原密码"。
网址可选填了之后卡片上的外链图标才能打开网站。
本地应用目标可选桌面版可一键启动该软件；网页版只保存、不执行。
分类可选留空归入「其他」。预设：开发 / 工作 / 娱乐 / 社交 / 购物 / 金融 / 其他。
标签可选用逗号或顿号分隔，如 工作, 常用，用于左侧「标签」导航。
备注可选任意补充说明。
可见性可选见第 8 节四种隐私档位。

内置密码生成器

编辑器里自带强密码生成器：可选长度 16 / 20 / 24 位，勾选是否包含小写、大写、数字、符号，点「生成」即用新密码填好。也可以点账号 / 密码框旁的粘贴图标，从剪贴板导入——粘贴来的密码不会自动显形，也不会写进任何提示或日志，保护你不被旁人瞄到。

6. 灵动岛与后台常驻

灵动岛是密岛的常驻小组件：建库并解锁后，你不用每次都打开大窗口，直接就能在灵 动岛上搜索、看最近使用、快捷建卡、复制账号/密码、跳转——它是真正可用的，而 不是只能看。

把主面板"收进"灵动岛（留在后台）

在完整主面板里，点窗口的关闭（×）或最小化（—），密岛不会退出，而是：

  1. 主面板缩成一个无边框、置顶的小岛贴在屏幕顶部（默认收起成一条，点一下展开）；
  2. 同时缩到系统托盘（任务栏不再显示密岛）。

这样密岛继续在后台运行，灵动岛始终可见、随时可点。首次"收进岛"会有一条轻提示告诉你如何彻底退出。

右键灵动岛，唤醒主面板

在灵动岛上点右键会弹出小菜单，三项：

菜单项作用
打开主面板把小岛还原成完整窗口（也可点托盘图标）。
锁定保险库立即锁定；已锁定时置灰（不摆假按钮）。
退出密岛真正退出进程（退出前会先清空剪贴板与计时器）。

托盘图标左键 = 打开主面板；右键托盘菜单同样有「打开主面板 / 锁定保险库 / 退出密岛」。

关闭 ≠ 退出。「关闭 / 最小化主面板」只是把密岛收进灵动岛与托盘，数据与会话仍在 后台。要彻底退出，请从右键灵动岛 → 退出密岛，或托盘菜单退出。

主面板里也有灵动岛预览条

当你打开完整主面板时，顶部工具条仍带一个可收缩的灵动岛预览条：点一下展开，同样能搜 索、建卡、复制——这是在主窗口内随手用的快捷入口，与"收进后台的小岛"是同一个功能的两处形态。

灵动岛是桌面版专属能力。若你使用的是网页预览，相关本地操作（如启动应用、收进后台） 不会执行，只会提示"桌面版将启动本地应用"。

7. 锁定、解锁与自动上锁

自动锁定

出于安全，密岛会在你一段时间不操作后自动上锁。默认策略是闲置 30 分钟。此外，当窗口切到后台、或系统锁屏 / 休眠时，也会立即上锁（这一项可在设置中关闭）。

你也可以在工具条随时点「锁定」手动上锁。

解锁

  1. 在解锁页输入主密码。
  2. 连续输错 2 次后，会出现「显示提示」按钮——点它可以看你在建库时写的密码提示。
  3. 继续输错会进入冷却倒计时，期间提交被禁用，倒计时结束才能再试。
  4. 若彻底想不起主密码，点「忘记密码？」走恢复流程（见第 9 节）。

每次锁定都会显示原因，例如"你刚刚手动锁定""超过自动锁定时间""系统锁屏或切到后台"等，让你清楚为什么被锁。

8. 四种隐私档位

每张卡片都可以设置"可见性"，控制它在列表里暴露多少：

档位含义
普通账号与密码都可查看、可复制。默认档位。
仅账号列表显示账号，密码只能复制、不可预览（预览按钮被禁用）。
隐藏不进入列表与搜索，必须二次验证主密码才能看到。适合高度敏感的条目。
遮罩留在列表里，但账号与密码用圆点遮住，验证主密码后才显示。适合"在别人面前打开密岛"的场景。

访问隐藏 / 遮罩卡片

  • 点左侧「隐藏卡片」会弹出验证框，要求再输一次主密码。验证通过后授权窗口为 120 秒，到期自动退出隐藏视图并提示你。
  • 「遮罩」卡片在列表里点开时，也会先要求验证主密码，验证通过才临时显示字段；到期后自动恢复遮罩。
  • 输错主密码时，会提示剩余可试次数，防止暴力猜测。
把卡片设为「隐藏」或「遮罩」只是额外的一层本地保护，并不能替代主密码。它防止的是"别人已经能开你电脑、且你已解锁"时的窥探。

9. 忘记主密码？用恢复码找回

如果你还记得恢复码（或保存的 .kirk 文件），就能重设主密码、拿回数据。

  1. 在解锁页点「忘记密码？」，进入恢复流程。
  2. 验证身份：输入 32 位恢复码（大小写和分隔符都不敏感），或选 / 粘贴 .kirk 文件内容。
  3. 设置新主密码：输入两次一致、且强度达标的新密码。
  4. 完成后会话会回到锁定态，用新主密码重新解锁即可。
重新设密后，旧的恢复码仍然有效（除非你主动轮换，见下）。但一旦主密码和恢复密钥同时丢失，数据将永久不可恢复——密岛没有服务器，也没有后门。

怀疑恢复码泄露？轮换它

在设置里可以「重新生成恢复密钥」：先验证主密码，再把旧恢复码 / 旧 .kirk 作废，生成一份全新的。注意：

  • 旧恢复码在生成成功的那一刻立即失效，没有过渡期。
  • 新恢复码只在此流程内出现一次，必须重新离线保存并勾选确认才完成。
  • 主密码不受影响；轮换后请用新 .kirk 做后续备份与恢复。

10. 加密备份与恢复

密岛的数据只存在你这台电脑上。做一份加密备份，是防止硬盘损坏、换电脑、系统重装后数据丢失的唯一办法。

导出加密备份（.kib）

  1. 打开「设置」，找到备份区域，点「导出 .kib 文件」。
  2. 为这份备份设置一个备份密码（可以与主密码不同）。
  3. 浏览器会下载一个文件，命名为 keyisland-YYYY-MM-DD.kib。
  4. 把 .kib 文件存到离线或另一处安全位置（U 盘、另一台设备）。
备份文件本身就是加密的（KIB1 格式：外层只有格式信息，里面的密码、密钥槽、偏好全部 AES 加密）。备份密码不会写进文件，所以即使别人拿到 .kib，没有密码也打不开。
恢复备份需要两样东西同时具备：① 你导出时设置的备份密码；② 对应的恢复密钥（.kirk 文件或恢复码）。两者缺一不可——请分别妥善保管。

何时会被提醒备份

设置里会显示「上次备份」状态。如果超过 7 天没备份，临近自动锁定或启动时会有轻提示，提醒你"该导出一份了"。

从备份恢复

在「设置 → 导入备份」里选择 .kib 文件（或直接粘贴内容），输入备份密码并配合.kirk / 恢复码，即可恢复。恢复有两种模式：

模式适用
覆盖导入用备份完整替换当前保险库。换电脑、硬盘坏了时用它。
合并只把备份里"当前库没有"的条目补进来；相同内容自动跳过，冲突项保留当前版本。仅当备份与当前库来自同一把密钥时才允许合并。

导入完成后，会话会回到锁定态，用主密码重新解锁即可看到恢复回来的数据。

12. 安全须知与常见疑问

密岛到底把数据存在哪？ 只存在你电脑的 vault.db 里，并且：
  • 主密码经 Argon2id 派生密钥，所有条目用 AES-256-GCM 逐条独立加密；
  • 解开数据库的密钥放在 Windows 凭据管理器（绑定当前 Windows 用户）；
  • 不联网、不同步、不上传。

常见疑问

Q：换台电脑 / 重装系统后还能打开吗？

A：数据库密钥绑定创建保险库时的那个 Windows 用户。换用户或重装系统后，凭据管理器里的密钥会丢失——这时数据文件还在但打不开。两种解法：① 换回原来的 Windows 用户；② 用之前的 .kib 加密备份"覆盖导入"。所以备份一定要做。

Q：可以把数据文件夹放进 OneDrive / 坚果云同步吗？

A：不建议。同步盘可能在密岛运行时锁住 vault.db，导致打不开（见第 13 节）。备份的 .kib 文件可以放进同步盘，但那是一个独立、已加密的文件，更合适。

Q：密岛会偷偷联网吗？

A：不会。程序本身不含任何网络请求；"检查更新"在当前版本也未启用联网。

Q：主密码和恢复码哪个更重要？

A：同样重要。忘主密码可用恢复码找回；但两者都丢就无解。请分别、离线保存。

13. 启动失败怎么办

如果双击图标后没有正常进入、或弹出"启动失败"页面，密岛会用中文说明原因并给出三步操作。常见几类：

现象含义与对策
数据还在，但解开它的密钥不在了数据库完整，但 Windows 凭据管理器里的密钥丢了（换用户 / 重装 / 清理工具删过凭据）。对策：换回原 Windows 用户；或用加密备份"覆盖导入"；确认无法找回时把 vault.db 改名留档再重建。
无法访问 Windows 凭据管理器读不到数据库密钥，数据本身无损。对策：确认用原用户登录；检查凭据管理器里的 KeyIsland 条目；重启后再试。
无法创建数据目录磁盘空间不足、权限被策略限制或安全软件拦截。对策：清空间 / 加白名单 / 点"打开数据文件夹"确认位置可写。
无法打开数据库文件另一个密岛进程占用、被同步盘锁住或文件损坏。对策：结束多余进程；暂停同步盘；先把 vault.db 复制留档再排查。

启动失败页提供两个按钮：「打开数据文件夹」（直接定位到 vault.db）和「重试」。先把重要文件复制留档，再按提示操作，必要时带着"具体原因"反馈给开发者。
