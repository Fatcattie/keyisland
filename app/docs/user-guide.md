# 密岛 KeyIsland · 操作指引与功能说明（终端用户版）

> 本地加密的密码保险库 —— **无云端、无服务器、无后门**。本手册帮你完成安装、建库、存取代号、主题切换、灵动岛快捷操作、备份与恢复，以及常见疑问。
> 适用版本：**v0.1.11**。

---

## 1. 关于本手册

- 这是一份**面向使用者**的手册：讲清楚「每个功能是什么」和「一步步怎么用」。
- 想看工程结构、构建与发版流程，请移步仓库根的 [`README.md`](../../README.md) 与 [`app/README.md`](../README.md)。
- 密岛是**桌面程序**（Windows 10 / 11，x64，需 WebView2 运行时）。通过浏览器打开的预览页只是演示，**数据只留内存、重启即清空，禁止放真实数据**。

## 2. 产品简介与安全模型

密岛把账号密码**只保存在你自己电脑上**，与「账号密码同步到厂商服务器」的工具不同：

- **没有云端账户**：无需注册、邮箱或联网。
- **没有后门**：数据用你的主密码在本地加密，开发者也无法打开。
- **没有网络请求**：运行时不与任何服务器通信（「检查更新」默认是关闭的显式开关，且当前未接入）。

> **一句话安全模型**：主密码 + 恢复码，是打开保险库仅有的两把钥匙。两把都丢，谁也救不了你的数据——包括密岛自己。

数据落盘方式：主密码经 Argon2id 派生密钥，条目以 SQLCipher（AES-256-GCM）逐条独立加密；解开库的密钥放在 **Windows 凭据管理器**（绑定当前用户）。不联网、不同步、不上传。

安装包**没有做代码签名**，首次运行 Windows SmartScreen 会提示「未知发布者」——点「更多信息」→「仍要运行」。想省掉这个提示只能去买签名证书。若安全软件拦截，请把密岛加入白名单，否则可能「图标一闪而过」（见第 16 节）。

### 3.3 首次启动向导

第一次打开进入**设置向导**，引导你创建保险库（见下一节）。

## 4. 创建你的保险库

向导分三步：

### 第 1 步 · 设置主密码
- **要求：至少 8 位，且包含以下四类中的至少两类**：小写字母、大写字母、数字、符号。
- 下方有**实时强度条**（弱 / 中 / 强）。

> 主密码是打开保险库的唯一钥匙之一，无法找回、无法重置（除非持有恢复码）。

### 第 2 步 · 密码提示（可选）
写一句只有你自己懂的提示，解锁时能看到。**提示不能含密码本身**，留空也可。

### 第 3 步 · 保存恢复码（最关键）
密岛生成一串 **32 位恢复码**（形如 `XXXX-XXXX-XXXX-XXXX-XXXX-XXXX-XXXX-XXXX`）。这一屏给你三件事：
- **复制恢复码**；
- **下载 `.kirk` 文件**；
- **勾选「我已离线保存」**才能点「进入密岛」。

> **务必离线保存**（纸或 U 盘），不要只留电脑里。一旦「恢复码丢失」**且**「主密码忘了」，数据**永久不可恢复**。

## 5. 主面板布局与日常使用

主面板三块：**左侧导航**（全部 / 收藏 / 分类 / 标签 / 隐藏卡片）、**顶部工具条**（搜索、网格⇄列表、排序、选择、预览灵动岛、锁定、新建）、**卡片网格**。

- **搜索**：按 `/` 聚焦搜索框，输入即过滤。
- **卡片操作**：
  - 收藏（☆）、复制账号 / 密码（默认 30 秒自动清空剪贴板）、**按住**预览密码（松开即隐藏）、打开链接（配了网址直接开；同时配本地应用弹二选一；仅本地应用桌面版启动）、编辑、删除。
  - 右下角三色点表示**密码强度**（红弱 / 黄中 / 绿强）。
- **批量删除**：选择模式勾选多张，删除需**重输主密码**。
- **状态条**：左侧「本地加密 · 无云端连接」，右侧「会话剩余 X」。
- **主题开关**：左侧导航底部有一个白天 / 黑夜切换（见第 6 节）。

## 6. 白天 / 黑夜主题

密岛提供两套外观：**白天**（浅色）与**黑夜**（深色）。

- **切换位置**：主面板**左侧导航最底部**的滑动开关（一个会「拉伸回弹」的胶囊开关：白色圆钮滑过 24px，途中压成横向椭圆再弹回）。点一下即可在白天 ⇄ 黑夜之间切换。
- **默认跟随系统**：首次打开时，密岛读取系统的「深色模式」偏好（macOS / Windows 的浅色或深色设置）。系统深色 → 密岛深色；系统浅色 → 密岛浅色，**不用你手动选**。
- **一旦手动切换过，就记住你的选择**：你只要拨动过一次开关，偏好会落盘保存，之后系统的变化**不再覆盖**你选的主题。如果之后想回到「跟随系统」，目前需要在系统层面改回对应外观（手动选择后即以你的选择为准）。
- **灵动岛恒为深色**：灵动岛（桌面常驻小岛）是独立的高对比度形态，**不参与主题切换**，始终深色，保证贴边常驻时清晰可读。

> 主题只改外观，不影响任何已加密的数据。

## 8. 灵动岛与后台常驻

**灵动岛是密岛的常驻小组件**：建库并解锁后，你不用每次都打开大窗口，直接就能在灵动岛上**搜索、看最近使用、快捷建卡、复制账号/密码、跳转**——它是真正可用的，而不是只能看。

### 8.1 把主面板"收进"灵动岛（留在后台）
在完整主面板里，点窗口的**关闭（×）或最小化（—）**，密岛不会退出，而是：
1. 主面板缩成一个**无边框、置顶的小岛**贴在屏幕顶部（默认收起成一条，点一下展开）；
2. 同时缩到**系统托盘**（任务栏不再显示密岛）。

这样密岛继续在后台运行，灵动岛始终可见、随时可点。首次"收进岛"会有一条轻提示告诉你如何彻底退出。

### 8.2 右键灵动岛，唤醒主面板
在灵动岛上**点右键**会弹出小菜单：

| 菜单项 | 作用 |
|---|---|
| 打开主面板 | 把小岛还原成完整窗口（也可点托盘图标）。 |
| 锁定保险库 | 立即锁定；已锁定时置灰（不摆假按钮）。 |
| 退出密岛 | 真正退出进程（退出前会先清空剪贴板与计时器）。 |

托盘图标左键 = 打开主面板；右键托盘菜单同样有「打开主面板 / 锁定保险库 / 退出密岛」。

> **关闭 ≠ 退出。**「关闭 / 最小化主面板」只是把密岛收进灵动岛与托盘，数据与会话仍在后台。要彻底退出，请从**右键灵动岛 → 退出密岛**，或托盘菜单退出。

### 8.3 主面板里也有灵动岛预览条
当你打开完整主面板时，顶部工具条仍带一个**可收缩的灵动岛预览条**：点一下展开，同样能搜索、建卡、复制——这是在主窗口内随手用的快捷入口，与"收进后台的小岛"是同一个功能的两处形态。

> 灵动岛是**桌面版专属**能力。若你使用的是网页预览，相关本地操作（如启动应用、收进后台）不会执行，只会提示"桌面版将启动本地应用"。

### 8.4 滚轮「滑动线」选择器（快速复制）
展开灵动岛后，在岛上**滚动鼠标滚轮**会唤出一条「滑动线」选择器，专门用来在不打开大窗口的情况下快速翻卡并复制：

| 操作 | 效果 |
|---|---|
| 滚轮**向下** | 从**第一张**卡片开始，逐张往下翻 |
| 滚轮**向上** | 从**最后一张**卡片开始，逐张往上翻 |
| `Enter` | 复制当前选中卡片的**密码** |
| `Shift + Enter` | 复制当前选中卡片的**账号** |
| **鼠标中键（按下滚轮）** | 退出滑动线，回到灵动岛面板（见下） |
| `Esc` | 关闭滑动线，但**不收起**整个岛 |

> **中键退出**是为「滚轮操作流」补的一个出口：滑动线打开时，按一下鼠标中键（滚轮键）就能退出选择、回到灵动岛面板，不必把鼠标挪到别处或连按 Esc。只有中键生效，左键不会误关。

## 9. 锁定、解锁与自动上锁

- **自动锁定**：默认**闲置 30 分钟**；切后台或系统锁屏/休眠也会立即上锁（可在设置关闭）。
- **手动锁定**：工具条点「锁定」。
- **解锁**：输主密码；连错 **2 次**后出现「显示提示」；继续错进入**冷却倒计时**（期间禁用提交）；想不起密码点「忘记密码？」走恢复流程。
- 每次锁定显示**原因**（手动 / 超时 / 系统锁屏或切后台等）。

## 10. 四种隐私档位

| 档位 | 含义 |
|---|---|
| 普通 | 账号密码都可看可复制（默认）。 |
| 仅账号 | 列表显示账号，密码**只能复制不可预览**（预览禁用）。 |
| 隐藏 | **不进列表与搜索**，需二次验证主密码才能访问。 |
| 遮罩 | 留列表但账号密码**圆点遮住**，验证主密码后才显示。 |

- 点「隐藏卡片」弹验证框，再输主密码；**授权窗口 120 秒**，到期自动退出并提示。
- 「遮罩」卡片点开也先验证，通过后临时显示，到期恢复。
- 输错主密码提示**剩余可试次数**。

> 隐藏/遮罩只是**额外一层本地保护**，不能替代主密码。

## 11. 忘记主密码？用恢复码找回

1. 解锁页点「忘记密码？」。
2. **验证身份**：输入 32 位恢复码（大小写/分隔符不敏感），或选/粘贴 `.kirk` 内容。
3. **设置新主密码**：两次一致且强度达标。
4. 完成后回到锁定态，用新主密码解锁。

> 重设后旧恢复码仍有效（除非主动轮换）。**主密码+恢复密钥同时丢失 = 永久不可恢复**。

**轮换恢复密钥**（怀疑泄露时）：设置里「重新生成恢复密钥」→ 先验主密码 → 旧码立即失效（无过渡期）→ 新码只出现一次，需重新离线保存并勾选确认。主密码不受影响。

## 12. 从 CSV 快速导入

CSV 导入适合把浏览器或其他密码工具导出的账号密码表格转换为密岛资产卡片。CSV 通常是明文文件，请只在可信设备上处理，并在导入确认后按你的安全策略删除临时文件。

1. 在设置 → 备份与恢复 →「从 CSV 迁移」点击「下载 CSV 模板」。模板包含名称、平台、账号、密码、网址、本地应用目标、分类、标签、备注表头；模板不含示例密码。
2. 用表格软件填写数据并另存为 CSV。**名称、账号、密码为必填列**；其余字段可以留空。标签可用逗号、分号或顿号分隔。
3. 点击「导入 CSV」并选择填写后的文件。密岛会尝试按中英文表头自动识别字段，并预览可导入条目数与跳过行数；预览不会显示密码。
4. 如果自动识别不正确，在「字段映射」中为各字段手动选择对应的 CSV 列。名称、账号、密码必须分别映射到不同列；其他字段可设为「不导入」。每次调整都会重新计算预览。
5. 检查预览后点击「导入」生成资产卡片。无法导入的行会显示行号和原因；可下载跳过行报告（不含账号或密码）以便修正源文件后重试。

- **只新增，不覆盖**：导入只会往库里追加卡片，不会修改或删除已有卡片。
- **重复自动跳过**：内容完全相同（标题、平台、网址、本地应用、账号、密码、备注、分类、标签、隐私档位和收藏状态均一致）的卡片会被跳过，因此同一个 CSV 导入两次不会产生重复卡片。字段有任何差异（例如多了网址）则作为新卡片保留。
- 导入成功的提示会如实汇报新增数与跳过数，例如「已导入 8 张卡片，2 张已存在」。

导入前请检查 CSV 的来源与内容。不要把包含真实密码的 CSV 通过不可信渠道传输，也不要把它当作加密备份。

## 13. 批量资产导出与导入

这项功能用于在**不同保险库之间迁移卡片**，与完整库备份不同。它只包含资产内容，不包含源库的密钥槽、恢复码、库设置或原始卡片 ID；导入时使用当前库密钥重新加密。

### 导出加密资产包（`.kia`）
1. 在已解锁的主面板打开「设置」→「备份与恢复」→「资产批量迁移」。
2. 输入**当前库主密码**。密岛会先验证密码，再生成加密资产包。
3. 保存 `keyisland-assets-YYYY-MM-DD.kia` 文件，并通过你信任的渠道传到目标设备。
4. `.kia` 文件内容经过 Argon2id 密钥派生与 AES-256-GCM 加密；没有正确密码时不能读取其中资产。

### 在目标保险库中增量导入
1. 在目标设备先安装密岛、创建或打开目标保险库，并解锁。
2. 设置 → 备份与恢复 → 资产批量迁移，选择 `.kia` 文件。
3. 输入**导出时使用的主密码**（源库主密码）。它仅用于解开资产包；不要求与目标保险库主密码相同。
4. 点击「预览导入结果」，查看文件资产总数、预计新增数与完全重复数。预览只读，不会写入目标库。
5. 确认后点击「确认增量导入」。目标库会把这些资产用自己的密钥重新加密后新增。

- 目标库中已有**完全相同**（标题、平台、网址、本地应用、账号、密码、备注、分类、标签、隐私档位和收藏状态均一致）的资产会跳过，避免重复。
- 其他卡片会新增；即使同一网站/账号但字段内容不同，也会作为新卡片保留。**导入不会修改或删除现有卡片**。
- 文件错误、密码错误或被篡改时，导入失败，目标库不发生变化。
- `.kia` 是迁移副本，不会自动同步。迁移成功后请确认目标库卡片齐全，再自行按安全策略处理传输文件；加密不等于可以公开分享，主密码也不要与文件放在同一渠道。

## 14. 加密备份与恢复

### 导出（.kib）
1. 设置 → 备份 → 「导出 .kib 文件」。
2. 设置**备份密码**（可与主密码不同）。
3. 下载 `keyisland-YYYY-MM-DD.kib`。
4. 存到离线/另一处安全位置。

> 备份文件本身已加密（KIB1：外层仅格式信息，内部 AES 加密），备份密码**不写进文件**。

> **恢复需要两样同时具备**：① 备份密码；② 对应的恢复密钥（`.kirk` 或恢复码）。缺一不可。

- **7 天未备份**会有轻提示。
- **恢复**：设置 → 导入备份，选 `.kib` + 备份密码 + `.kirk`/恢复码。
  - **覆盖导入**：完整替换当前库（换电脑/硬盘坏用）。
  - **合并**：只补"当前库没有"的条目，相同跳过，冲突保留当前；仅同密钥世系允许合并。
- 导入后回到锁定态，用主密码解锁。

## 17. 安全须知与常见疑问

**数据存在哪**：只存本机 `vault.db`；主密码经 Argon2id 派生密钥，条目 AES-256-GCM 逐条独立加密；解开库的密钥放 **Windows 凭据管理器**（绑定当前用户）；不联网、不同步、不上传。

- **Q：换电脑/重装还能开吗？** 密钥绑定原 Windows 用户。换用户/重装后凭据丢失，数据在但打不开 → 换回原用户，或用 `.kib` 覆盖导入。**务必做备份。**
- **Q：能放 OneDrive/坚果云同步吗？** 不建议，同步盘可能锁住 `vault.db` 致打不开。备份的 `.kib`（独立已加密文件）可放同步盘。
- **Q：会偷偷联网吗？** 不会。程序本身无网络请求，检查更新也未启用。
- **Q：主密码和恢复码哪个重要？** 同等重要。忘主密码可用恢复码找回；都丢则无解。请分别离线保存。
- **Q：主题切换会动到我的数据吗？** 不会，主题只改外观。灵动岛始终深色，不受切换影响。

## 18. 启动失败怎么办

双击无反应或弹"启动失败"页，会中文说明原因并给三步操作：

| 现象 | 含义与对策 |
|---|---|
| 数据在但密钥不在 | 凭据管理器密钥丢了（换用户/重装/清理工具）。对策：换回原用户；或用 `.kib` 覆盖导入；确认无法找回则把 `vault.db` 改名留档再重建。 |
| 无法访问凭据管理器 | 读不到密钥，数据无损。对策：用原用户登录；查 KeyIsland 条目；重启。 |
| 无法创建数据目录 | 空间不足/权限限制/安全软件拦截。对策：清空间/加白名单/打开文件夹确认可写。 |
| 无法打开数据库 | 另一进程占用/同步盘锁/损坏。对策：结束多余进程；暂停同步盘；先复制 `vault.db` 留档。 |

启动失败页提供「打开数据文件夹」与「重试」。先复制重要文件留档，再按提示操作。
